## 问题判定标准

### 🔴 P0 判定条件
- 断链：链接指向的文件不存在
- 路径不存在：文档中明确提到的文件/目录路径不存在
- 虚构命令：文档中的命令在项目中不可用（如 Makefile 中没有该 target）

### 🟡 P1 判定条件
- 符号不存在：文档中明确引用的函数/宏名称在代码中找不到
- 内容过时：文档描述与当前代码实现明显不符
- 硬编码数值：文档中的数值在代码中有对应的宏定义，但文档未引用

### 🔵 P2 判定条件
- 命名不规范：文件名不符合 `xxx_yyy.md` 格式
- 缺少元数据：文档没有状态标记或更新时间
- 引用深度过深：从 L0 到该文档的最短路径 >3 层

### 🟣 缺失文档判定条件
- 代码目录缺少 README.md
- 独立模块（>500 行代码）缺少设计文档或使用手册

### ⚪ 待人工复核判定条件
- 命令需要实际执行才能验证
- 硬编码数值无法判断是否为客观事实
- 符号可能是外部库提供的（AI 无法访问外部库代码）

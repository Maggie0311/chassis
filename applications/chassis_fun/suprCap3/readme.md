# 绪论

由于队内先前使用的功率控制存在较大问题，参数测量依旧麻烦，控制效果不好，尤其是低功率的情况下存在走不直，走不快的情况，在功率受限时陀螺模式时几乎无法移动，对于能量回收的研究几乎没有，对于电机参数的认识也不足。本赛季基于此开发新的功率控制模块，开发需求主要有

* 强大的鲁棒性
* 更加准确的电机模型
* 方便调试和维护
* 更广的适用性

### 功率控制整体可解耦为以下部分
* 首先是如何识别底盘系统，对底盘电机建立功率模型，通过模型来预测底盘电机所消耗的功率
* RLS计算得出模型的参数
* 计算可输出的最大功率
* 预测功率与可输出的最大功率进行比较，若小于直接输出，若大于则进行限制以及后续的功率再分配与新的输出扭矩的反解

# 功率模型
单个底盘电机所消耗的功率为

$$
{P}_i = \tau_iv_i + k_1\left|v_i\right|  + k_2\tau_i^2 + c
$$
(目前该功率模型来自于港科开源，原模型使用公式可见刘超先生语雀推导
https://hitwhlc.yuque.com/hero-rm/uqpee6/tedglql6fi1ckgeq
两个公式很相近，只是原公式使用的$k_1$项是$v^2$,目前使用RLS后，两者效果其实并无明显差异 :yum:)


| 描述                           | 符号       |
| ------------------------------ | ---------- |
| 第i个电机消耗的总功率          | $P_i$      |
| 第i个电机实际输出的力矩        | $\tau_i$   |
| 第i个电机实际的转速            | $v_i$ |
| 电机的静态损耗                 | $c$        |
| 电机转速产生的功率损耗系数     | $k_1$      |
| 电机力矩平方产生的功率损耗系数 | $k_2$      |

而综合底盘多个电机，我们得到了以下模型

$$
P = \sum_{i = 1}^{n}\bold{P}_i = \sum_{i = 1}^{n}\tau_iv_i + k_1\sum_{i = 1}^{n}\left|v_i\right|  + k_2\sum_{i = 1}^{n}\tau_i^2 + k_3
$$
其中，$P$为底盘总消耗功率，n为电机数量（标准4轮底盘则为4），$k_3$为整个底盘系统的静态损耗（$k_3 = \sum_{i = 1}^{n}c_i$，由于k3相对较小，我们也可以简单地直接认为$c = k_3 / n$)
# 递归最小二乘算法（RLS）

 使用RLS来帮助我们拟合电机模型的参数。递归最小二乘法是一种自适应算法，用于通过递归方式估计参数值。在电机模型中，RLS可以动态地调整参数，以适应系统的变化和环境的影响。这不仅极大的减少了用户调参的时间，提高了模块的广泛适用性，不需要再对每个不同的底盘或是不同的电机手动调参。与其他团队不断费心调试相比，这种方法可以一劳永逸，非常便捷。
    k1、k2、k3 是我们需要识别的参数,c可以由静态时裁判系统反馈得到,不需要参与RLS更新的过程。因此我们
只需要通过一个二维的RLS更新就可以实时获得一套准确的电机功率计算参数。
  已对该算法进行了验证，验证过程详见语雀文档https://hitwhlc.yuque.com/hero-rm/uqpee6/dbuaqw5wfx30di83
# 功率分配方法
  原功率分配方法是直接功率受限时直接乘上一个功率衰减系数，即PowerCtrl.k_power_allo_wheel，但由于改系数涉及到运动解算时的一个功率受限时降低平移性保证跟随性的函数耦合在一起，所以暂时没有删掉。
  现参考港科开源，当误差较小时等比缩放，当误差较大时按误差分配，中间按线性关系拟合。用一个置信度变量标定误差大小。
# 扭矩反解
  通过计算预输出功率和可以获得的最大功率进行比较，功率分配，我们已经得到了底盘每个电机的合理的输出功率。

  * 在无刷电机中，电流和扭矩近似成线性关系，通过查看电机手册，我们可以得知电机的力矩常熟，通信协议输出值约定等参数，用于将通信的输出值和力矩（Nm）互相转换
* 我们可以认为电机的力矩闭环速度是很快的($f > 1000Hz$)。 因此，我们可以假设力矩指令等于反馈力矩，即$\tau_{cur} = \tau_{feedback}$。为了方便表述，简称这两项为$\tau$。
* 在一个控制周期内(\$f = 1000Hz\$)，电机的实际角速度\$\\Omega\_{cur}\$相对于实际力矩的变化是很小的。、
* 每个电机的静态损耗可以约等于$k_3 / n$
* 别的关于转速平方，力矩一次的损耗项可以忽略为0

代入每个电机所分配到的功率，以及电机的实时转速，$k_1$，$k_2$和$k_3$，我们可以得到一个关于力矩$\tau_i$的一元二次方程

$$
k_2\tau_i^2 + v_i\tau_i + k_1\left|v_i\right| + k_3 / n - {P}_i  = 0
$$

$$
A\tau_i^2 + B\tau_i + C = 0
$$

$$
A = k_2 \qquad B = v_i \qquad C = k_1\left|v_i\right| + k_3 / n - {P}_i
$$

$$
\Delta = v_i ^2 - 4k_2(k_1\left|v_i\right| + k_3 / n - {P}_i)
$$

如果$\Delta < 0$，方程无实数解（可以理解为没有一个力矩能够在当前转速下输出到指定功率），我们用$\tau_i = \frac{-B}{2A}$作为一个近似解

$$
\tau_i = \frac{-v_i}{2k_2}
$$

如果$\Delta = 0$，即重复根，$\tau_i = \frac{-B}{2A}$

$$
\tau_i = \frac{-v_i}{2k_2}
$$

如果$\Delta > 0$，此处我们可以得到两个力矩的解，而这两个解都能够让电机消耗这个功率的值。这个模型可以考虑到力矩和转速方向不同时输出力矩产生的反电动势，而此处为了保证功率控制不影响底盘正常运动，我们取用符号与原PID输出符号一致的解，即

* 如原PID输出为正，$\tau_i = \frac{-B + sqrt(\Delta)}{2A}$
  $$
  \tau_i = \frac{-\omega_i + \sqrt{\omega_i^2 - 4k_2(k_1\left|\omega_i\right| + k_3 / n - {P}_i))}}{2k_2}
  $$
* 如原PID输出为负，$\tau_i = \frac{-B - sqrt(\Delta)}{2A}$
  $$
  \tau_i = \frac{-\omega_i - \sqrt{\omega_i^2 - 4k_2(k_1\left|\omega_i\right| + k_3 / n - {P}_i))}}{2k_2}
  $$


# 舵轮底盘
轮向电机和舵向电机各为一组，分别失能一组电机，用RLS拟合出未失能组的参数，注意首次测量参数时应避免低功率时的拟合和长时间匀速直线平移或陀螺,选取功率受限时反解扭矩后实际输出功率与预输出功率大致相等的参数。
如果标定的参数效果较好，其实完全可以在运行时关闭RLS的更新。也可以固定一组的参数，另一组的参数使用RLS在线计算




  
# 调试关键变量
Power_Set     主要存放设定的各类功率和分配的相关参数   
PowerInfo   主要存放裁判系统和超电测得的底盘功率等参数
PowerCtrl   主要查看算得的最大可输出功率

ERRhigh与ERRlow为功率分配时确定置信度的两个阈值，需要在调试时根据PowerSet.ERROR_Sum给定合适的数值，不需要很精确。

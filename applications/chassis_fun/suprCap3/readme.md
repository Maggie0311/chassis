# 基于 RLS 的底盘功率控制

## 绪论

由于队内先前使用的功率控制存在较大问题，参数测量依旧麻烦，控制效果不好，尤其是低功率情况下存在走不直、走不快的情况，在功率受限时陀螺模式几乎无法移动，对于能量回收的研究几乎没有，对于电机参数的认识也不足。本赛季基于此开发新的功率控制模块，开发需求主要有：

* 强大的鲁棒性
* 更加准确的电机模型
* 方便调试和维护
* 更广的适用性

### 整体架构

功率控制整体可解耦为以下部分：

* 对底盘电机建立功率模型，通过模型预测底盘电机所消耗的功率
* 使用 RLS 在线辨识模型参数
* 计算可输出的最大功率
* 将预测功率与可输出最大功率进行比较：若小于则直接输出，若大于则进行限制，并进行功率再分配与输出扭矩反解

## 功率模型

### 单电机工程功率公式

单个底盘电机所消耗的功率为

$$
P_i = \tau_iv_i + k_1\left|v_i\right| + k_2\tau_i^2 + c
$$

> 该功率模型参考港科开源，原模型可见[语雀文档](https://hitwhlc.yuque.com/hero-rm/uqpee6/tedglql6fi1ckgeq)。
> 两者很相近，只是原公式 $k_1$ 项使用的是 $v^2$。使用 RLS 后，两者效果并无明显差异。

| 描述 | 符号 |
| --- | --- |
| 第 i 个电机消耗的总功率 | $P_i$ |
| 第 i 个电机实际输出的力矩 | $\tau_i$ |
| 第 i 个电机实际的转速 | $v_i$ |
| 电机转速产生的功率损耗系数 | $k_1$ |
| 电机力矩平方产生的功率损耗系数 | $k_2$ |
| 电机的静态损耗 | $c$ |

### 功率模型推导

以下从物理第一性原理出发，推导上述工程公式的理论依据。

#### 1. 基本电功率关系

电机的输入总功率 $P_{in}$ 由直流母线电压 $U_{DC}$ 和电流 $I_{DC}$ 决定：

$$P_{in} = U_{DC} I_{DC}$$

在 FOC（磁场定向控制）框架下，将三相交流电映射到同步旋转坐标系（$d$-$q$ 轴）。绕组中消耗的有功功率 $P_e$ 可表示为：

$$P_e = U^T I = U_q I_q + U_d I_d$$

#### 2. FOC 简化假设

在大多数机器人驱动器中，采用 $I_d = 0$ 的控制策略以获得最大的扭矩/电流比。此时，电磁功率简化为：

$$P_e = U_q I_q$$

#### 3. 电功率分解

根据 $q$ 轴电压方程 $U_q = K_e\omega_m + RI_q + L_q\dfrac{dI_q}{dt}$，代入功率公式：

$$
\begin{aligned}
P_e &= \left(K_e\omega_m + RI_q + L_q\frac{dI_q}{dt}\right)I_q \\
    &= K_e I_q \omega_m + I_q^2 R + \frac{L_q}{2}\frac{d I_q^2}{dt} \\
    &= T_e\omega_m + I_q^2 R + \frac{dW_L}{dt}
\end{aligned}
$$

各项物理意义：

* $T_e\omega_m$：电磁转换功率，转化为机械能的部分
* $I_q^2 R$：铜损，绕组电阻发热
* $\dfrac{dW_L}{dt}$：电感储能变化（稳态运行或周期性平均时，该项均值为 0）

#### 4. 额外损耗分析

实际系统中，还存在以下额外损耗：

* **静态功耗**：电调逻辑电路、传感器及电机待机时的能量消耗
* **铁损**：包括磁滞损耗（$\propto \omega_m$）和涡流损耗（$\propto \omega_m^2$）
* **机械摩擦损耗**：与转速相关的轴承及风阻摩擦

综合表示为（$\alpha_i$ 为推导中间系数，与最终工程符号 $k_i$ 不同）：

$$P_{loss} = \alpha_0 + \alpha_1|\omega_m| + \alpha_2\omega_m^2$$

#### 5. 宏观工程模型推导

将微观物理量（电流、电压）转换为宏观机械量（扭矩、转速）：

**扭矩与电流的关系**（$I_d = 0$ 时）：

$$\tau = K_t I_q \implies I_q = \frac{\tau}{K_t}$$

**铜损项替换**，将 $I_q = \tau / K_t$ 代入：

$$P_{copper} = \left(\frac{\tau}{K_t}\right)^2 R = \frac{R}{K_t^2}\tau^2$$

其中 $\dfrac{R}{K_t^2}$ 即为工程公式中的 $k_2$。

**输出机械功率**：

$$P_m = \tau \cdot \omega_m$$

**损耗合并**：将铁损与静态功耗合并，并将二次项线性化，以 $k_1$ 作为速度线性损耗系数，$c$ 作为静态功耗：

$$P_{other} \approx k_1|\omega| + c$$

#### 6. 最终功率模型

综合以上推导，单个电机的输入总功率模型为：

$$\boxed{P_{in} = P_m + k_2\tau^2 + k_1|\omega| + c}$$

与工程公式 $P_i = \tau_iv_i + k_1|v_i| + k_2\tau_i^2 + c$ 完全对应。

| 符号 | 物理含义 | 推导来源 |
| --- | --- | --- |
| $P_{in}$ | 总输入功率 | 电池端直流总功率 $U_{DC}I_{DC}$ |
| $P_m = \tau\omega$ | 输出机械功率 | 电磁转换项 $T_e\omega_m$ |
| $k_2\tau^2$ | 铜损项 | $k_2 = R/K_t^2$，电流经过电阻的发热 |
| $k_1\|\omega\|$ | 铁损与摩擦损耗 | 磁滞损耗线性化合并项 |
| $c$ | 静态功耗 | 系统电路基础消耗与静态损耗补偿 |

### 底盘综合功率模型

综合底盘多个电机，得到底盘总功率模型：

$$
P = \sum_{i=1}^{n} P_i = \sum_{i=1}^{n}\tau_iv_i + k_1\sum_{i=1}^{n}\left|v_i\right| + k_2\sum_{i=1}^{n}\tau_i^2 + k_3
$$

其中 $P$ 为底盘总消耗功率，$n$ 为电机数量（标准4轮底盘为4），$k_3$ 为整个底盘系统的静态损耗（$k_3 = \sum_{i=1}^{n}c_i$，由于 $k_3$ 相对较小，可简单地认为 $c = k_3 / n$）。

## 递归最小二乘算法（RLS）

使用 RLS 来帮助拟合电机模型的参数。递归最小二乘法是一种自适应算法，用于通过递归方式估计参数值。在电机模型中，RLS 可以动态地调整参数，以适应系统的变化和环境的影响。这不仅极大减少了用户调参的时间，提高了模块的广泛适用性，不需要再对每个不同的底盘或电机手动调参。

$k_1$、$k_2$、$k_3$ 是需要辨识的参数，$c$ 可以由静态时裁判系统反馈得到，不需要参与 RLS 更新过程。因此只需通过一个二维的 RLS 更新就可以实时获得一套准确的电机功率计算参数。

已对该算法进行了验证，验证过程详见[语雀文档](https://hitwhlc.yuque.com/hero-rm/uqpee6/dbuaqw5wfx30di83)。

## 功率分配方法

原功率分配方法是在功率受限时直接乘上一个功率衰减系数（`PowerCtrl.k_power_allo_wheel`），但由于该系数与运动解算时一个"功率受限时降低平移性、保证跟随性"的函数耦合在一起，所以暂时没有删掉。

现参考港科开源：当误差较小时等比缩放，当误差较大时按误差分配，中间按线性关系拟合。用一个置信度变量标定误差大小。

## 扭矩反解

通过功率分配，已得到底盘每个电机的合理输出功率。反解所基于的几个假设：

* 在无刷电机中，电流和扭矩近似成线性关系。通过查看电机手册，可得知电机的力矩常数、通信协议输出值约定等参数，用于将通信输出值和力矩（N·m）互相转换
* 电机的力矩闭环速度很快（$f > 1000\text{ Hz}$），因此可以假设力矩指令等于反馈力矩，即 $\tau_{cur} = \tau_{feedback}$，简称为 $\tau$
* 在一个控制周期内（$f = 1000\text{ Hz}$），电机的实际角速度 $\Omega_{cur}$ 相对于实际力矩的变化很小
* 每个电机的静态损耗可近似为 $k_3 / n$
* 关于转速平方、力矩一次的损耗项可忽略为 0

代入每个电机分配到的功率、实时转速以及 $k_1$、$k_2$、$k_3$，得到关于力矩 $\tau_i$ 的一元二次方程：

$$
k_2\tau_i^2 + v_i\tau_i + k_1\left|v_i\right| + k_3 / n - P_i = 0
$$

令

$$
A = k_2, \quad B = v_i, \quad C = k_1\left|v_i\right| + k_3 / n - P_i
$$

则判别式为：

$$
\Delta = v_i^2 - 4k_2\left(k_1\left|v_i\right| + k_3 / n - P_i\right)
$$

**情形一：$\Delta < 0$**，方程无实数解（没有一个力矩能在当前转速下输出到指定功率），取近似解：

$$\tau_i = \frac{-v_i}{2k_2}$$

**情形二：$\Delta \geq 0$**，可以得到两个力矩的解，两者都能让电机消耗指定功率。为保证功率控制不影响底盘正常运动方向，取符号与原 PID 输出一致的解：

* 若原 PID 输出为正：
  $$\tau_i = \frac{-v_i + \sqrt{v_i^2 - 4k_2(k_1\left|v_i\right| + k_3/n - P_i)}}{2k_2}$$

* 若原 PID 输出为负：
  $$\tau_i = \frac{-v_i - \sqrt{v_i^2 - 4k_2(k_1\left|v_i\right| + k_3/n - P_i)}}{2k_2}$$

## 负功率与刹车

根据公式，当扭矩与速度方向相反时，电机可能出现负功率。经测试，裁判系统对于负功率会当作 0 处理，因此底盘出现负功率时无需进行功率限制。

但需注意：扭矩与速度方向相反（刹车）是出现负功率的必要不充分条件。对于刹车时出现的正功率，仍然需要进行限制，这可能导致刹不住车、车辆停止时较卡顿的情况——这表示当前机器人在当前功率限制下不支持该速度，需要从控制源上降低最大速度。

## 舵轮底盘适配

轮向电机和舵向电机各为一组，分别失能一组电机，用 RLS 拟合出未失能组的参数。

注意首次测量参数时应避免低功率时的拟合，以及长时间匀速直线平移或陀螺；选取功率受限时反解扭矩后实际输出功率与预输出功率大致相等的参数。

如果标定参数效果较好，可以在运行时关闭 RLS 的更新，也可以固定一组的参数，另一组使用 RLS 在线计算。

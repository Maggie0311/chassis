# 哨兵底盘软件系统架构文档

> **平台**：RT-Thread RTOS，STM32 主控
> **机型**：哨兵（`sentry_omni`），全向轮底盘（4轮45°全向轮布局）
> **编译宏**：`CORE_USING_SENTRY` / `USING_OMNI_RESOLVE`

---

## 一、总体架构概览

```
┌─────────────────────────────────────────────────────────────────────┐

│   Monitor | CAN | Ref | SuperCap | Gimbal | ChassisCtrl | UI        │
└───────────────────────────────┬─────────────────────────────────────┘
                                │ 初始化 & 线程拉起
        ┌───────────────────────┼────────────────────┐
        ▼                       ▼                    ▼
 ┌──────────────┐      ┌─────────────────┐   ┌─────────────────┐
 │  外部通信层   │      │   底盘控制层     │   │   功能辅助层     │

```

## 三、底盘控制主线程流水线

`app_ChassisCtrl.c` 以 **2ms** 为节拍，驱动如下流水线：

```
┌────────────────────────────────────────────────────────────┐
│                Chassis_Ctrl_Thread（2ms）                   │
│                                                            │
│  1. 读取当前最高优先级数据源（controlMsg 仲裁结果）           │
│          ↓                                                  │
│  2. mod_motion 运动模式解析                                  │
│     · FOLLOW_GIMBAL  → 坐标系变换（yaw 对齐）               │
│     · SLOW/FAST_GYRO → 小陀螺角速度叠加                     │
│     · CHASS_AUTO     → 视觉/自主目标速度注入（哨兵模式）      │
│          ↓                                                  │
│  3. 速度设定值规划（二阶平滑，drv_SetPlanning）               │
│          ↓                                                  │
│  4. drv_motionSolve 全向轮逆解算                             │
│     Omni_Inverse_Kinematics_45 → 4轮目标转速（RPM）         │
│          ↓                                                  │
│  5. 写入各电机设定值 → 唤醒 PID_Cal_Thread                   │
└────────────────────────────────────────────────────────────┘
                          ↓（信号量唤醒）
┌────────────────────────────────────────────────────────────┐
│                PID_Cal_Thread（电机线程）                    │
│                                                            │
│  1. Motor_Control_Loop → 各轮速度 PID 计算 → 扭矩指令        │
│  2. Power_Ctrl（suprCap3）→ 功率限制 + 扭矩反解              │
│  3. Motor_Transmit_Loop → CAN 发送电机指令                   │
│  4. Forward_Kinematics → 正解算，更新实际底盘速度             │
└────────────────────────────────────────────────────────────┘
```

## 四、多数据源仲裁机制（controlMsg）

底盘控制指令来自多个数据源，通过**优先级抢占**机制选取当前有效源：

| 数据源 | 枚举 | 默认优先级 | 哨兵是否启用 |
|---|---|---|---|
| 监视器（急停） | `CS_MONITOR` | 4（最高） | 是 |
| 视觉/自主运动 | `CS_Visual` | 3 | 条件启用（云台遥控器触发） |
| 测试遥控器 | `CS_TEST` | 2 | 否（调试用） |
| 云台控制指令 | `CS_GIMBAL` | 1（最低） | 是（正常运行） |

各数据源通过 `Source_WriteData_s()` 写入数据，`getNowCtrlSrc_s()` 返回当前优先级最高的有效源，数据超时则自动降级。

## 五、运动学解算（全向轮）

哨兵使用 **4轮45°全向轮**布局，对角轮间距 $D = 608\text{ mm}$，轮径 $r = 80\text{ mm}$。

逆解算矩阵将底盘期望速度 $(V_x, V_y, \omega)$ 映射至各轮角速度：

$$\begin{bmatrix} \omega_{RF} \\ \omega_{LF} \\ \omega_{LB} \\ \omega_{RB} \end{bmatrix} = \frac{1}{r} \begin{bmatrix} -\sin 45° & \cos 45° & D/2 \\ -\sin 135° & \cos 135° & D/2 \\ -\sin 225° & \cos 225° & D/2 \\ -\sin 315° & \cos 315° & D/2 \end{bmatrix} \begin{bmatrix} V_x \\ V_y \\ \omega \end{bmatrix}$$

正解算（`Forward_Kinematics`）通过伪逆矩阵由各轮反馈转速估计底盘实际运动状态，用于小陀螺下的坐标系修正。

## 六、功率控制集成（suprCap3）

功率控制作为 **PID_Cal_Thread 内的后处理步骤**嵌入，调用链为：

```
Motor_Control_Loop()           ← 速度 PID → 原始扭矩指令 τ_pid
        ↓
Power_Ctrl()                   ← fun_powerCtrl.c
    ├─ RLS 参数更新              ← RLS.c，每拍更新 k1/k2
    ├─ 功率估计                  ← P_est = Σ(τω + k2τ² + k1|ω| + k3)
    ├─ 功率分配                  ← 置信度加权，各电机分配 P_i*
    └─ 扭矩反解                  ← 一元二次方程求解 → τ_cmd
        ↓
Motor_Transmit_Loop()          ← 发送反解后的扭矩指令
```

超电通过 CAN 上报实测功率，作为 RLS 的观测输入 $P_{\text{meas}}$；同时接收底盘下发的功率预算（裁判系统功率上限 + 缓冲能量）。

## 七、关键线程一览

| 线程名 | 周期/触发 | 优先级（参考） | 职责 |
|---|---|---|---|
| `Chassis_Ctrl_Thread` | 2ms | 高 | 运动模式解析 + 逆解算 |
| `PID_Cal_Thread` | 信号量（同步于控制线程） | 高 | PID + 功率控制 + CAN 发送 |
| `CAN Rx Thread` | 中断驱动 | 极高 | 接收云台/超电/电机反馈 |
| `Ref_Thread` | UART DMA 中断 | 极高 | 裁判系统数据解析 |
| `UI_Thread` | ~100ms | 低 | 裁判系统 UI 刷新 |
| `Monitor_Thread` | 周期 | 最低 | 看门狗喂狗超时检测 |
| `protect_Thread` | 周期 | 高 | 电机离线保护 |

## 八、配置隔离机制

代码通过**编译宏 + robotData 子目录**实现多机型支持，哨兵相关配置集中在 `robotData/sentry_omni/`：

- `robot_data.h`：轮距、轮径、速度/加速度限幅、动力学参数（质量 20kg、转动惯量 0.5 kg·m²）
- `robot_control.h/c`：功率模型参数 $k_1$、$k_2$、$c$（初始先验值，运行时由 RLS 修正）、PID 参数、CAN ID 分配
- `robot_message.c`：电机 CAN 报文注册，将 CAN 帧与电机结构体绑定

切换机型只需在 SConscript 中引用不同的 `robotData/` 子目录，上层控制代码无需修改。

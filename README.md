# 2026 底盘控制系统

## 简介

本项目是基于 RT-Thread RTOS 的 RoboMaster 底盘控制系统，支持多机型配置。

主要内容：

- 底盘运动控制（全向轮/麦轮）
- 功率控制与超级电容管理
- 裁判系统通信与 UI 显示
- 多数据源仲裁机制

## 支持机型

- 哨兵（全向轮）
- 步兵
- 英雄

## 快速开始

### 编译

使用 Keil MDK：

1. 打开 `project.uvprojx`
2. 点击 Build 编译
3. 点击 Download 下载到开发板

使用命令行：

```bash
scons
```

### 运行

1. 连接开发板电源
2. 连接串口（115200-8-1-N）查看日志
3. 系统自动启动，LED 指示运行状态

## 核心特性

- **多数据源仲裁**：支持云台、视觉、遥控器等多个控制源，自动优先级管理
- **精确功率控制**：基于 RLS 在线参数辨识的功率模型，实时功率预测和分配
- **模块化设计**：代码按功能分层，易于维护和扩展
- **多机型支持**：通过配置文件快速切换不同机型

# 测试验收指引

## 测试流程

1. **编译固件**
   - 按照[编译构建指引](build_guide.md)编译代码

2. **烧录固件**
   - 使用 Keil MDK 或 J-Link 烧录

3. **功能测试**
   - 连接串口（115200-8-1-N）查看日志
   - 连接遥控器测试底盘运动
   - 检查裁判系统通信
   - 验证超电功率控制

4. **调试工具**
   - VOFA+ 波形监控（`applications/test/vofa.c`）
   - MSH 命令行调试（`applications/test/cmd.c`）

## 测试检查项

- [ ] 系统正常启动，无错误日志
- [ ] 底盘响应遥控器指令
- [ ] 云台通信正常
- [ ] 裁判系统数据接收正常
- [ ] 超电通信和功率控制正常
- [ ] UI 显示正常
